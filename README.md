# To-Do & Notes App

A responsive React application that combines a To-Do App and a Notes App in one place.

## Features

### To-Do App
- Add new tasks
- Mark tasks as completed
- Edit tasks
- Delete tasks
- View task status as Completed or Pending
- Filter tasks by All, Completed, and Pending
- Save tasks using Local Storage

### Notes App
- Create notes
- Edit notes
- Delete notes
- View all notes
- Search notes
- Display created/updated timestamps
- Save notes using Local Storage
